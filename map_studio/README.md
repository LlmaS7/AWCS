# AWCS 地图工坊

本目录是随AWCS提交版提供的独立地图生成器与地图管理器。它包含完整的生成核心和浏览器页面，可单独启动；正式校验、试运行和导出使用同一提交目录中的主程序与 `maps/`，不需要原 `SDITADC` 开发仓库。

## 启动

推荐先在主目录运行一次 `setup.bat`，之后任选一个入口：

- 双击主目录的 [launch_map_studio.bat](../launch_map_studio.bat)。
- 双击本目录的 [launch.bat](launch.bat)。
- 在仓储仿真调试窗口点击“地图工坊 ↗”。

也可在主目录执行：

```powershell
.\.venv\Scripts\python.exe map_studio/main.py
```

地图工坊本身只使用Python标准库，不需要API Key、Node或新增Python包；仅使用此工具时，也可用已安装的Python直接运行：

```powershell
python map_studio/main.py
```

独立启动会显示本机地址并打开浏览器。关闭网页不等于关闭服务；在启动终端按 `Ctrl+C` 结束。由主程序打开的服务随主程序关闭。

## 生成地图并用于仿真

1. 选择规整、L形、T形、U形、庭院、组合房间或随机组合轮廓，填写尺寸、机器人容量、种子和货架/障碍参数。
2. 点击“生成并预览”，检查地图和静态校验。生成预览不会保存文件或改变当前仿真。
3. 建议先从16台开始“规划试运行”，再验证目标数量和任务种子。
4. 填写名称和新的英文/数字文件标识，点击“保存为新地图”，得到 `library/<标识>.json`。
5. 点击“导出到 v0.4 地图列表”，得到主目录下的 `maps/<标识>.json`。
6. 回到仿真调试窗口，点击“刷新列表”，选择地图和机器人数量，再“应用并重置”。此操作清空任务并保持暂停，保留现场应先保存。

新保存、导入和导出不覆盖同名文件；需要新标识。地图库原稿与已导出地图是独立副本，原稿重命名或归档不会改变已导出的文件。

## 功能与限制

| 项目 | 范围 |
| --- | --- |
| 轮廓 | 规整、L/T/U形、庭院、组合房间、随机组合 |
| 生成参数 | 宽48～128、高40～96；1～64台容量；货架净通道2～6格；64台为实验档 |
| 业务点 | 相邻出发池、取送作业点、正式货架到取货点映射、有限停车区 |
| 地图快照 | 保留生成器版本、参数、种子与完整静态网格；生成的障碍固定在快照中 |
| 地图库 | 搜索、分组、载入、另存、重命名、归档和下载 |
| 导入 | `sditadc-map` v1 JSON，最多2 MB；错误输入不替换当前预览 |
| 校验 | 主程序正式格式、容量、四邻域连通、相邻起点前缀及货架业务关系检查 |
| 试运行 | 隔离子进程执行有限任务批，记录任务完成数、碰撞数、种子与快照摘要 |

候选货架填充率是候选位置的采样概率，不是最终地面面积占比。通道、端点等受保护，空间不足时障碍数量可能少于请求值，以实际预览为准。

静态检查通过不代表多机器人一定可解；有限试运行通过也不代表长期无死锁。32台及以上应结合具体地图、任务和预算验证，不能把地图容量当成已认证吞吐能力。预算不足或未完成会如实标记，不声称数学无解。

不支持任意多边形手绘、图片识别导图、动态障碍或真实机器人控制。地图管理是调试功能，不向AI业务助手提供地图写入工具。

## 目录及数据

| 文件/目录 | 职责 |
| --- | --- |
| `generator.py` | 独立生成算法 |
| `legacy.py` | 旧矩形内置图的兼容生成实现 |
| `bridge.py` | 在隔离解释器中调用主程序校验和试运行 |
| `storage.py` | 地图库、归档及防同名覆盖 |
| `manager.py` | 本机HTTP服务与后台任务 |
| `main.py`、`launch.bat` | 独立启动入口 |
| `frontend/` | 浏览器管理页与Canvas预览 |
| `library/` | 使用时按需创建，保存原稿；`archive/`为归档，`reports/`为试运行报告 |
| `../maps/` | 主程序地图列表，也是本提交版的导出目的地 |

提交版不携带测试、开发验收报告或个人地图库。三张轮廓示例位于主目录 `maps/`，可以在工坊的主程序地图分组中载入，不需要重复复制到 `library/`。

仅监听本机127.0.0.1，校验Host/Origin；不提供任意本机路径读写。校验和试运行子进程不读取模型设置或Key。主程序与地图工坊应作为同一目录整体移动，避免丢失校验模块或把地图导出到错误位置。
