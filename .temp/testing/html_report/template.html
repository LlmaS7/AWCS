A / 任务分配

用穷举核对匹配结果

在小规模输入中，独立枚举可行分配，比较等级、偏好和预计完成时间等目标。额外检查匈牙利矩阵求解。

另有 120 组矩阵穷举对照及业务边界用例；不表示大规模全局路径最优。
B / 路径规划

用另一种方法检查搜索

独立的逐时间步动态规划对照单机器人 SIPP，覆盖预约、等待、连续作业和交付；预约与小型联合状态另有检查。

200组独立时空对照
参考检查器不调用生产搜索或生产预约区间计算。
C / 执行保护

检查故障与真实状态

注入损坏路线、过期结果、规划超时和进程异常，检查人工暂停、任务归属与装卸是否保持一致。

25项最终回归测试
包含真实控制器线程与独立规划进程的小场景验证。
两个判据，分别报告路线与执行安全：是否满足碰撞、障碍和装卸约束。
任务完成：是否在该次规划与运行预算内排空预设任务。
这一页怎么讲任务匹配用独立穷举核对，单机器人搜索用独立时空方法核对。之后还要检查返回路线和逐步执行，最后统计任务是否完成。不要把匹配子问题的最优性扩展成所有任务和路线的联合全局最优。

HOW TO READ

“未完成”代表什么？

当次预算内没有形成新的安全方案，系统暂停并保留现场。它没有证明地图无解，也没有把未经验证的路线交给机器人。

本轮 5 项未完成包含 3 个规模场景和 2 个动态流场景，细节保留在下表。

06

CONCLUSION / 讲解摘要

可以据此说明什么。

固定版本、明确输入、
独立检查、保留边界。

主场景覆盖多种布局与不同随机实例；核心检查和执行审计支持算法与保护机制的验证。扩大规模和持续任务流仍需结合搜索预算评估。

AWCS 在最多 32 台的测试范围内，通过了 1,715 项任务分配、路径规划与执行保护核心检查，以及最终版本的 25 项针对性回归测试。7 类布局、2 组固定种子形成 14 张不同随机地图，4/16 台的 28 个主场景全部完成；32 台规模场景完成 5/8，有限动态任务流完成 1/3，其余用例在规划预算内安全停止并单独披露。范围内 50 份轨迹复审未发现所检路线及执行的冲突、装卸或证书约束违规。结论适用于所测版本、地图、任务和预算，不代表任意任务流下的全局最优或长期无死锁。
