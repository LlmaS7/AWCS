# 测试报告使用说明

双击 AWCS_测试报告.html 即可离线打开，无需启动项目或联网。

- 阅读模式：滚动查看完整报告。
- 讲解视图：按章节展示，左右方向键切换，Esc 返回阅读模式。
- 讲解提示：显示每节可直接口述的提示。
- 随机地图：筛选布局、点击放大、查看两种规模的实际结果，或跳转该地图回放。
- 轨迹回放：播放/暂停、拖动时间线、选择机器人和播放速度，观察归档真实轨迹。
- 打印：通过浏览器打印保存为 PDF；动画以当前画面呈现。
- 所有地图、样式与回放数据均已内嵌，分享 HTML 文件即可。另附测试地图总览.svg，便于放入讲解材料。

数据沿用现有归档及最终 Agent 语义复核，未重新运行算法或模型测试。随机地图为 7 类布局、2 个固定生成种子，共 14 张；每张测试 4/16 台。32 台、动态流、64 台追加实验、Agent 成绩分别呈现，不合并计算总体通过率。

新版报告共 12 章，新增以下内容：

- Agent 最终成绩：146 PASS、10 FAIL、1 INCONCLUSIVE，主矩阵 23 段及 U/X 专项 30 段未运行。D07/r3 的实际未授权取消导致安全验收失败。
- 60 种场景逐次成绩：可按能力组、结果及关键词筛选，点击结果查看冻结输入模板、复核依据、回答摘录及原始证据目录。
- D07 失败链路、全部失败及未完成样本、文档约束归类、64 台追加实验条件。
- 证据索引：归档报告实际位于 `.report/test_res`；最终复核附件仍位于同级 SDITADC 项目。单独分享 HTML 时，所有内嵌正文、地图、回放和复核摘要仍可阅读；原始文件链接需保留本地目录结构。

算法与 Agent 结论各自适用于记录版本，不自动代表当前工作树通过验收。报告已区分 32 台最终交付口径与 64 台历史实验口径，并核验 raw 日志哈希变化仅来自项目根路径替换；未修改原始证据或归档 Markdown 报告。
