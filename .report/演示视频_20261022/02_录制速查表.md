## 可复制的助手输入

先查询：

```text
请查询当前可用的取货点和配送点，并简要说明当前任务情况。
```

创建主线任务：

```text
新建一项搬运任务：从 P01 取货，送到 D1，优先级为2级，执行1次。
```

核对完成情况，替换实际编号：

```text
查询 T010 的当前状态。
```

文件分析说明：

```text
提取本次待执行搬运需求，保留原文中的取送地点、优先级和搬运次数。
```

## 现场卡住时

| 情况 | 处理 |
| --- | --- |
| AI 等待较久 | 保留真实操作和回执，剪掉中间等待，并标注；不连续重发 |
| 文件无法拖入 | 确认已打开 AI 助手且无请求处理中；使用“添加文件”完成同一流程 |
| 草稿有误 | 核对原文，编辑正确后再确认；尚未检查的结果不能当成成功 |
| 没看到紧急抢占 | 展示优先级更新和实际接单，使用正文通用讲解；不声称已发生抢占 |
| 规划暂停 | 查看真实提示，按需“重试规划”；未恢复则重新排练场景，不能配成持续完成 |
| 工坊试运行未完成 | 展示实际结果，或正片只保留生成与静态检查 |
| 时长过长 | 先裁工坊保存/导出，再裁重复查询与长路程；保留同编号闭环、原理和结果 |
